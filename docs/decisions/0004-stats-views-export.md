# 0004. 통계·저장된 뷰·내보내기(5단계)

상태: 채택(2026-09-08).

## 1. 통계는 조건별 독립 쿼리, 같은 배치 상한

- `compute_stats`는 건수·NULL 시간·최소/최대 시각, 상태별, 메서드별, 상위 N IP/경로(N ≤ 100), 시간축을 각각 별도 SQL로 계산한다. 모두 같은 `max_batch_id`로 범위를 고정한다.
- 시간축은 DuckDB `time_bucket`으로 묶고 버킷은 [60초 … 1년] 후보 중 목표 400개 이하가 되는 첫 크기를 고른다. 2000개를 넘으면 앞쪽만 돌려주고 잘렸음을 표시한다. 요약 테이블(summaries)은 만들지 않았다. 10GB에서 전체 스캔이 수백 ms~수 초라 초기에는 필요 없다고 판단했다.
- 취소: 무거운 조회는 읽기 연결의 `InterruptHandle`을 기록해 두고 `cancel_heavy`가 `interrupt()`를 부른다. 중단된 쿼리는 "조회를 중단했습니다" 오류로 돌아온다.

## 2. 저장된 뷰는 프로젝트 DB 안에

- `saved_views`에 조건·정렬·컬럼을 JSON으로 저장한다. 같은 이름은 덮어쓴다. 컬럼은 허용 목록으로 검증한다. 읽기는 읽기 연결(`ViewQuery`), 쓰기는 가져오기 중 거부된다.

## 3. 내보내기는 커서 페이지 → 디스크 스트리밍

- `export_logs`는 `export_page`(전체 컬럼, 1000행)로 읽어 `BufWriter`로 바로 쓴다. 전체 결과를 모으지 않는다. CSV는 RFC 4180 따옴표 규칙을 직접 적용하고, JSON Lines는 행마다 객체 하나다. 시간은 ISO 8601 UTC, 확장 필드는 컬럼/객체로 포함한다.
- 취소하면 지금까지 쓴 파일을 남기고 `cancelled = true`로 알린다. 내보내기 전용 읽기 연결을 프로젝트가 하나 더 가진다(가져오기 중에도 내보낼 수 있다).

## 4. 화면

- 통계 화면은 단일 계열 막대(시간축)와 가로 막대(상태·메서드·상위 N)만 쓴다. 단일 계열이라 범례 없이 제목이 계열을 말하고, 값은 툴팁과 "표로 보기"로 읽는다. 막대 두께 24px 상한, 데이터 끝만 둥글게, 격자는 1px 실선.
- 조회 화면의 뷰 선택은 폼에 조건을 채우고, 내보내기는 저장 대화상자로 경로를 받아 백그라운드로 실행한다. 진행 표시는 상단 띠에 나타나며 취소할 수 있다.

## 개정(2026-09-08): 저장된 뷰 → 분석 룰

- 사용자 검토에서 저장된 뷰를 "YARA 룰 같은 분석 관점"으로 쓰기로 했다. 결과 화면 왼쪽 사이드바가 기본 룰(`src/lib/rules.ts`, 테스트 있음)과 사용자 룰(저장된 뷰 그대로)을 나열하고, 고른 룰의 조건을 조회·통계에 적용한다. 조회 화면의 뷰 선택·저장·삭제 컨트롤은 사이드바의 +/−로 옮겼다.
- 서명 검사를 위해 `LogFilter`에 `target_regex`(RE2, `regexp_matches(request_target, ?)`)를 추가했다. 바인딩 전에 Rust `regex`로 문법을 확인해 오류를 분명히 하고, 길이 상한은 부분 문자열 검색과 같다. CLI `query --target-regex`로 같은 조건을 재현할 수 있다.
- 기본 룰의 서명은 룩어라운드·역참조 없이 작성해 DuckDB(RE2)와 JS 정규식 양쪽에서 같은 결과가 나오도록 했고, 대표 페이로드와 평범한 경로로 테스트한다.

## 개정 2(2026-09-08): YARA풍 룰 언어

- 폼 기반 룰 추가는 "라벨로는 표현력이 부족하다"는 검토에 따라 텍스트 룰 언어로 바꿨다. 문법은 YARA를 따르되 필드·연산을 접근 로그에 맞게 줄였다(`src/lib/yara.ts`). 파서는 위치가 있는 오류를 내고, 편집기가 그 줄을 강조한다.
- 엔진 `LogFilter`에 조건식 트리 `expr`(and/or/not/cond, 노드 256·깊이 16 상한, 컬럼은 열거형, 값은 바인딩, 숫자 컬럼은 정수 검증, 정규식은 Rust regex로 선검증)를 추가했고 조회·건수·통계·내보내기가 공유한다. 저장된 뷰에는 `rule_source`를 함께 저장해 원문으로 다시 편집한다.
- 조회 막대는 룰이 조건을 담으므로 기간·빠른 검색·정렬만 남겼다. 빠른 검색은 경로·IP·리퍼러·UA를 OR로 묶은 조건식이다.
