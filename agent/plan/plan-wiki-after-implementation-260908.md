문서 지침 수정이므로 테스트 코드를 추가하지 않고 요청 사항 반영과 문서 공백을 확인한다.

- [x] AGENTS.md에 기능 완료 후 위키 반영 규칙과 PLAN 항목을 추가한다.
  근거: AGENTS.md의 문서 관리 절에 등재 대상·시점·기록 방식을 추가하고 PLAN 관리 절과 예시에 위키 반영 항목을 추가했다.
- [x] 변경 내용과 문서 공백 오류를 확인한다.
  근거: `rg`로 추가 규칙을 확인했고 `git diff --check`가 종료 코드 0으로 통과했다. 문서 변경으로 빌드·테스트는 실행하지 않았다.
