# 테스트 우선 검증 절차 명시

문서 지침 수정이므로 테스트 코드를 추가하지 않고, 요청 사항 반영과 문서 일관성을 확인한다.

- [x] AGENTS.md에 테스트 작성 → 기능 구현 → 테스트 실행·결과 확인 순서를 명시한다.
  근거: AGENTS.md의 PLAN 관리 절에 단계별 체크박스와 테스트 우선 작성 규칙을, 검증 절에 실제 실행·통과 확인·실패 시 재실행 규칙을 추가했다.
- [x] 기존 테스트 지침과 위키의 안내를 일치시킨다.
  근거: AGENTS.md의 스킬 적용 지침을 기능 추가·변경·버그 수정에 맞췄고 docs/testing.md에 공통 PLAN·검증 규칙 링크를 추가했다.
- [x] 변경 내용과 문서 공백 오류를 검사한다.
  근거: AGENTS.md와 docs/testing.md의 수정 구간을 확인했으며 `git diff --check`가 종료 코드 0으로 통과했다. 문서 변경으로 빌드·테스트는 실행하지 않았다.
