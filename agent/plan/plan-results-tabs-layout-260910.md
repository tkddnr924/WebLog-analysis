# 결과 화면 탭 위치·디자인 (2026-09-10)

## 요청
접근 로그 / 에러 로그 선택을 `[룰]` 사이드바 위(화면 최상단, 전체 너비)로 옮기고, 탭 디자인을 다시 한다.

## 설계
- 계층을 눈에 보이게 나눈다. 1단계(로그 종류)는 보고 있는 **자료 자체**가 바뀌는 것이라 서류철 탭처럼 종이 면이 앞으로 나오는 형태로, 사이드바와 본문을 함께 얹은 면 위에 붙인다. 2단계(조회·통계)는 같은 자료를 보는 **방식**이라 작은 분절 스위치로 낮춘다.
- 강조색은 1단계 활성 탭 위쪽 2px 한 줄에만 쓴다(나머지는 종이·선 대비로만 구분).
- 색·서체는 기존 토큰을 그대로 쓴다. 새 색을 만들지 않는다.

```
┌──────────────────────────────────────────────┐
│ ▛접근 로그▜  에러 로그                        │  ← 서류철 탭(전체 너비, 아래 선에 붙음)
├───────────┬──────────────────────────────────┤
│ 룰        │ [조회│통계]                       │  ← 분절 스위치
│ 기간      │  ...본문...                       │
└───────────┴──────────────────────────────────┘
```

레이아웃·CSS 변경이라 단위 테스트 대신 실제 화면 렌더로 확인한다(AGENTS.md 테스트 예외 사유).
