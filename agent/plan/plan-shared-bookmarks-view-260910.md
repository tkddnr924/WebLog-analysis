# 북마크를 두 로그가 함께 보기 (2026-09-10)

## 증상
에러 로그 화면의 "북마크" 룰에 접근 로그에서 단 별이 보이지 않는다(그 반대도 같다).

## 원인
북마크 표 자체는 `(source_id, line_number)` 하나라 공유되지만, 조회 조건에 화면의 로그 종류(`log_kind`)가 항상 얹힌다. 그래서 각 화면은 자기 종류의 북마크만 본다.

## 설계
- "북마크" 룰은 종류를 묻지 않는다(`log_kind: null`). 접근·에러에서 단 별을 한 목록에서 본다.
- 두 종류의 컬럼이 다르므로 북마크 목록은 **시간 + 내용** 두 칸만 쓴다(별 토글 칸 포함). 내용은 접근 로그면 `메서드 대상 · 상태 · IP`, 에러 로그면 `레벨 · 메시지`로 한 줄로 만든다.
- 조회 탭에서 북마크 룰이 선택되면 종류별 패널 대신 공용 북마크 목록을 보여준다. 통계 탭은 지금처럼 종류별로 둔다.
